# 02 - UX Principles & User Goals

This directory contains specifications defining user personas, visitor goals, journey pathways, and operational UX success principles.

- **[UX Index](file:///d:/Projects/SamjuniorsWebsite/docs/website/02-ux-principles/ux-index.md)**: Master index tracking UX deliverables, decision records, and cognitive frameworks.
- **[UX Decision Log](file:///d:/Projects/SamjuniorsWebsite/docs/website/02-ux-principles/ux-decision-log.md)**: Structured decision records for `UX-001` through `UX-012`.
- **[UX-001: Primary User Personas](file:///d:/Projects/SamjuniorsWebsite/docs/website/02-ux-principles/ux-001-personas.md)**: Target persona profiles for Students, Institutions, Businesses, Developers, and Investors.

- **[Cognitive UX Principles](file:///d:/Projects/SamjuniorsWebsite/docs/website/02-ux-principles/cognitive-ux-principles.md)**: Psychological foundations, cognitive load theory, and human-computer interaction models.
