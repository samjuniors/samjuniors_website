### Narrative & Cognitive Principles
- **[UX-005](file:///d:/Projects/SamjuniorsWebsite/docs/website/03-ux-principles/ux-decision-log.md#ux-005-progressive-discovery)**: Progressive Discovery (One idea per scene; layered depth on demand).
- **[UX-006](file:///d:/Projects/SamjuniorsWebsite/docs/website/03-ux-principles/ux-decision-log.md#ux-006-visitor-led-discovery)**: Visitor-Led Discovery (Answer visitor's next logical question).
- **[UX-007](file:///d:/Projects/SamjuniorsWebsite/docs/website/03-ux-principles/ux-decision-log.md#ux-007-scene-based-storytelling)**: Scene-Based Storytelling (Cinematic scenes: *Curiosity → Excitement → Understanding → Trust → Action*).
- **[UX-008](file:///d:/Projects/SamjuniorsWebsite/docs/website/03-ux-principles/ux-decision-log.md#ux-008-zero-fatigue-principle)**: Zero Fatigue Principle (Effortless reading through generous whitespace and optimal line lengths).
- **[UX-009](file:///d:/Projects/SamjuniorsWebsite/docs/website/03-ux-principles/ux-decision-log.md#ux-009-cognitive-load-first)**: Cognitive Load First (Evaluate components against mental load; eliminate unnecessary friction).
- **[UX-010](file:///d:/Projects/SamjuniorsWebsite/docs/website/03-ux-principles/ux-decision-log.md#ux-010-user-mental-model-first)**: User Mental Model First (Structure by user outcomes, not internal corporate divisions).
- **[UX-013](file:///d:/Projects/SamjuniorsWebsite/docs/website/03-ux-principles/ux-decision-log.md#ux-013-understanding-must-accompany-curiosity)**: Understanding Must Accompany Curiosity (Cinematic reveals must never compromise continuous comprehension).
- **[UX-014](file:///d:/Projects/SamjuniorsWebsite/docs/website/03-ux-principles/ux-decision-log.md#ux-014-interaction-must-earn-its-friction)**: Interaction Must Earn Its Friction (Every interaction must deliver positive value-to-friction ratio).
- **[UX-015](file:///d:/Projects/SamjuniorsWebsite/docs/website/03-ux-principles/ux-decision-log.md#ux-015-visitor-control)**: Visitor Control (Guides attention without taking control; zero scroll-jacking or forced waits).
- **[UX-016](file:///d:/Projects/SamjuniorsWebsite/docs/website/03-ux-principles/ux-decision-log.md#ux-016-progressive-disclosure)**: Progressive Disclosure (Align with Instant, Understand, Deep Dive non-linear layers).

### Navigation & Responsive Principles
- **[UX-011](file:///d:/Projects/SamjuniorsWebsite/docs/website/03-ux-principles/ux-decision-log.md#ux-011-hybrid-navigation)**: Hybrid Navigation (Familiar global navigation, subtle scroll transformation, single primary CTA, 100% accessible).
- **[UX-012](file:///d:/Projects/SamjuniorsWebsite/docs/website/03-ux-principles/ux-decision-log.md#ux-012-hybrid-scroll--progression-model)**: Hybrid Scroll & Progression Model (Zero scroll-jacking; natural scroll control; animation purpose test).
- **[UX-017](file:///d:/Projects/SamjuniorsWebsite/docs/website/03-ux-principles/ux-decision-log.md#ux-017-mobile-is-first-class)**: Mobile Is First-Class (Independently composed responsive experience; zero hover-dependencies).
- **[UX-018](file:///d:/Projects/SamjuniorsWebsite/docs/website/03-ux-principles/ux-decision-log.md#ux-018-predictable-restrained-navigation)**: Predictable Restrained Navigation (Wayfinding clarity preserved; no navigation hidden for drama).
- **[UX-019](file:///d:/Projects/SamjuniorsWebsite/docs/website/03-ux-principles/ux-decision-log.md#ux-019-recovery--continuity)**: Recovery & Continuity (Every state has an intuitive, non-destructive recovery path).
