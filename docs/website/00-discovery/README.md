# 00 - Website Discovery

This directory is dedicated to **Phase 1: Website Discovery**.

---

## Purpose
Capture and document foundational discovery assets prior to architectural or visual design:
- Project goals and success metrics
- Stakeholder interviews and alignment notes
- Target audience personas, user needs, and use cases
- Functional, non-functional, and compliance requirements
- Competitive analysis and benchmark notes

---

## Documents & Artifacts
- **[Discovery Index](file:///d:/Projects/SamjuniorsWebsite/docs/website/00-discovery/discovery-index.md)**: Master index tracking stages and completion status.
- **[Decision Log](file:///d:/Projects/SamjuniorsWebsite/docs/website/00-discovery/decision-log.md)**: Log of all formal discovery phase decisions (WD-001 through WD-014).
- **[Stage 1: Vision & Strategy](file:///d:/Projects/SamjuniorsWebsite/docs/website/00-discovery/stage-01-vision-and-strategy.md)**: Approved vision, audience priority, brand personality, positioning, scope, and success criteria.
- **[Stage 2: Brand Story & Identity](file:///d:/Projects/SamjuniorsWebsite/docs/website/00-discovery/stage-02-brand-story-and-identity.md)**: Approved narrative framework, brand message, differentiators, emotional journey, archetype, voice, visual personality, and positioning.
- **[Canonical Brand Foundation](file:///d:/Projects/SamjuniorsWebsite/docs/website/brand-foundation.md)**: Core canonical source of truth for brand narrative and identity.
