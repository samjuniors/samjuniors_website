# 05 - UI Design

This directory is dedicated to **Phase 6: UI Design**.

---

## Purpose
Document high-fidelity visual layouts, interactive states, and presentation specifications:
- High-fidelity visual mockups and layout definitions
- Interactive states: default, hover, focus, active, disabled, loading, error
- Micro-interactions, animation timings, and transition specifications
- Final exported visual asset manifests

---

## Guidelines
- UI designs must strictly consume tokens and patterns from [docs/website/04-design-system/](file:///d:/Projects/SamjuniorsWebsite/docs/website/04-design-system).
- Designs must be approved before beginning Frontend Development.
