# 01 - Information Architecture

This directory is dedicated to **Phase 2: Information Architecture**.

---

## Purpose
Define the structural organization, navigation paths, and page hierarchy for the website:
- Comprehensive site map
- Page taxonomy and relationship hierarchy
- User journey maps and navigation flowcharts
- URL routing schema and slug structure

---

## Documents & Artifacts
- **[Architecture Manifesto](file:///d:/Projects/SamjuniorsWebsite/docs/website/architecture-manifesto.md)**: Constitutional architecture foundation, quality gates, and freeze policy.
- **[Stage 3 Certification](file:///d:/Projects/SamjuniorsWebsite/docs/website/01-information-architecture/stage-3-certification.md)**: 10-dimension architectural audit and official freeze sign-off.
- **[IA Index](file:///d:/Projects/SamjuniorsWebsite/docs/website/01-information-architecture/ia-index.md)**: Master index tracking IA deliverables and completion status.
- **[IA Decision Log](file:///d:/Projects/SamjuniorsWebsite/docs/website/01-information-architecture/ia-decision-log.md)**: Log of all formal information architecture decisions (IA-001 through IA-009, WD-015 through WD-027).
- **[Homepage Architecture Specification](file:///d:/Projects/SamjuniorsWebsite/docs/website/01-information-architecture/ia-01-homepage-architecture.md)**: Certified homepage journey, primary navigation, hero strategy, narrative architecture, and progressive product ecosystem.
- **[Design & UX Principles](file:///d:/Projects/SamjuniorsWebsite/docs/website/design-principles.md)**: UX rules, signature moments, progressive disclosure, and honest roadmap standards.
